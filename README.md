# Case-Study-Car-Dekho-Price-Predection

🚗 Car Price Prediction — CarDekho Dataset
📌 Project Overview
This project focuses on predicting used car prices using the CarDekho dataset. The objective is to analyze key factors influencing car prices and build a machine learning model to estimate selling prices based on vehicle attributes.
The workflow includes data cleaning, exploratory data analysis (EDA), feature engineering, encoding, model training, and performance evaluation.

🎯 Objectives
Understand factors affecting used car prices
Perform exploratory data analysis to identify patterns and trends
Prepare data through preprocessing and feature engineering
Build a regression model for price prediction
Evaluate model performance using standard metrics

📊 Dataset Description
The dataset contains information about used cars such as:
Vehicle age
Kilometers driven
Fuel type
Seller type
Transmission type
Mileage
Engine capacity
Max power
Number of seats
Selling price (target variable)

🔎 Exploratory Data Analysis (EDA)
Performed:
Univariate analysis (distribution plots)
Bivariate analysis (feature vs price relationships)
Correlation heatmap
Outlier observations
Feature importance insights

Key findings:
Engine and max power show strong positive correlation with price
Vehicle age negatively impacts price
Mileage has moderate influence

🛠 Data Preprocessing
Removed irrelevant columns
Checked for missing values and duplicates
Converted categorical variables using One-Hot Encoding
Prepared feature matrix and target variable
Split data into train and test sets

🤖 Model Building
Used:
Linear Regression
Model evaluation metrics:

R² Score
Mean Squared Error (MSE)
Mean Absolute Error (MAE)
The model achieved moderate performance, indicating scope for improvement with advanced models.

📈 Results
Model captures general price trends
Some variance remains due to non-linear relationships
Further improvement possible using tree-based models
